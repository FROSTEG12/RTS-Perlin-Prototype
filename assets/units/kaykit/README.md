# Пять персонажей KayKit Adventurers 2.0

Автор Kay Lousberg, CC0 — оригинальная лицензия в License.txt. Исходная папка
пользователя не изменялась. Использованы Knight, Ranger, Barbarian, Rogue и
Rogue_Hooded. Mage исключён согласно описанию сеттинга в README исходного набора.
Оружие отдельно не подключено, боевой механики нет.

Все пять имеют родной Skeleton3D на 23 кости. Масштаб в игре 0.55: рост примерно
1.2–1.4 мировых единицы с учётом шлемов. 5800/8900/7123/7562/7185 треугольников
соответственно. Это подсчёт мешей, не результат массового FPS-теста.

Общая locomotion.res: 24 исходных клипа General и MovementBasic (без двух T-Pose),
плюс три ссылки idle=Idle_A, walk=Walking_A, jog=Running_A. Циклические только
idle/walking/running, остальные одноразовые. Сейчас управление использует idle/jog.
Клипы урона, смерти, прыжков и взаимодействия доступны в библиотеке, но не включают
соответствующих игровых механик. Атак, рубки, добычи и строительства в наборе нет.

Исходные GLB в source/.gdignore оставлены для воспроизводимости, Godot не импортирует
их в игру. tools/build_kaykit.gd загружает GLB через GLTFDocument офлайн, проверяет
совпадение rest-поз и костей у источника анимации и Knight, переписывает пути треков
на Skeleton3D и сохраняет PackedScene для каждой модели. В тесте проверяются
все пути и skin-привязки пяти моделей, общая библиотека и независимые AnimationPlayer.
Четыре исходные PNG лежат в textures; два Rogue используют одну текстуру.

Сборка: импортировать textures в Godot, затем запустить движок с
`--headless --path <project> --script res://tools/build_kaykit.gd`.
Проверка на GPU: `--path <project> --script res://tests/kaykit_models_test.gd`.
Старый Quaternius worker сохранён в соседней папке worker для возврата/сравнения.
