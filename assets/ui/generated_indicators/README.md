## Направление генерации

Original raster game HUD icons for a modern medieval RTS. Softly sculpted painted
enamel, broad smooth shading, clean edges, chunky recognizable silhouettes readable
at 24–32 pixels. Transparent background, front view, centered, about 80% of canvas.
No text, watermark, badge, circle, UI panel, arrows, faces, tiny details or scene.

Сюжеты отдельных запросов: утро — золотой восход с лучами и заполненным светлым
низом под горизонтом; день — золотое солнце с восемью лучами; вечер — оранжевый
закат без лучей с заполненным персиковым низом; ночь — серебряный полумесяц и
одна звезда; пасмурно — перекрывающиеся серебристые облака; дождь — синеватая
туча и три крупные капли без молнии; туман — низкая дымка с двумя широкими
завитками, не прямые полосы меню.
