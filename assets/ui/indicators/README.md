# HUD: сутки и погода

Собственные SVG, нарисованы для этого проекта. Не системные emoji и не скачанные иконки.
Единый viewBox 32×32, исходный размер 128×128 для сглаживания при малом размере HUD.
Утро: крупный восход с тремя лучами и одним горизонтом; день: полное солнце;
вечер: закат без лучей; ночь: светлый полумесяц со звездой.
У восхода и заката под горизонтом сплошная округлая заливка в цвет черты,
стрелок нет. Лучи и тёплые цвета отличают утро от вечера.
Погода: те же солнце/луна для ясного неба, сплошное облако, туча с двумя
крупными каплями, низкое облако с двумя волнами дымки. Плоские светлые силуэты,
толщина основных штрихов 3–3.5/32, без градиентов, бликов и мелких полос.
Отрисовка 24 px внутри неизменного кольца 36 px, погодные значки 28 px.
Без текстовых подписей в панели, описания остаются в tooltip.
