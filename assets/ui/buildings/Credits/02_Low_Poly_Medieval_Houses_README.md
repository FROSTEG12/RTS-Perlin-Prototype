# Low Poly Medieval Houses Pack

Набор домов для выбора и адаптации под игровые здания.

Источник: https://sketchfab.com/3d-models/low-poly-medieval-houses-pack-440f780e414b4a2abd535b5c55838223

Файл: `low_poly_medieval_houses_pack.glb`. Оригинальный GLB сохранён без изменений. Материалы и текстуры находятся внутри файла; внешних ссылок на файлы нет.

Для редактирования: импортируйте GLB в Blender через File → Import → glTF 2.0. Сохраните рабочую копию в .blend. Объединение и назначение игровых ролей ещё не выполнялось.

Лицензию и требования к указанию автора смотрите на странице источника.
