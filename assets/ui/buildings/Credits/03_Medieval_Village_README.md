# Medieval Village

Деревня: здания и элементы окружения для дальнейшего объединения.

Источник: https://sketchfab.com/3d-models/medieval-village-0e7dd1fd2cd64f828b625021e30704d4

Файл: `medieval_village.glb`. Оригинальный GLB сохранён без изменений. Материалы и текстуры находятся внутри файла; внешних ссылок на файлы нет.

Для редактирования: импортируйте GLB в Blender через File → Import → glTF 2.0. Сохраните рабочую копию в .blend. Объединение и назначение игровых ролей ещё не выполнялось.

Лицензию и требования к указанию автора смотрите на странице источника.
