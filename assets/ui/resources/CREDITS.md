# HUD resource icons

The resource toolbar now uses original generated PNG illustrations in
`../generated_resources/`, not the legacy SVG resource icons listed below.
The warriors symbol remains in use. menu.svg and the other navigation SVGs
are project-native vector artwork.

- wood.svg, metal.svg, warriors.svg: Kenney, Board Game Icons, CC0.
  https://kenney.nl/assets/board-game-icons
- stone-pile.svg, coal-pile.svg, steak.svg, berries-bowl.svg: Delapouite,
  Game-icons.net, CC BY 3.0: https://creativecommons.org/licenses/by/3.0/
  Sources: https://game-icons.net/1x1/delapouite/stone-pile.html
  https://game-icons.net/1x1/delapouite/coal-pile.html
  https://game-icons.net/1x1/delapouite/steak.html
  https://game-icons.net/1x1/delapouite/berries-bowl.html

Kenney SVG viewboxes set to -32 -32 64 64; runtime tint/size adjusted for the HUD.
No downloaded building artwork is used.
