# Структура проекта

Базовая сцена — `scenes/main.tscn`, ровно 10 синих рыцарей.
Боя, NPC-спарринга, обхода соседей, столкновений тел и тестового строительства нет.
Текущее простое управление временное: ЛКМ/рамка, ПКМ, Shift-очередь, S, пробел.
Его последующая замена не должна затрагивать рендеринг и генерацию мира.

| Папка | Ответственность |
| --- | --- |
| scripts/app | Сборка мира и запуск систем |
| scripts/world | Генерация, чанки, берега, деревья и края карты |
| scripts/environment | Погода, день/ночь и освещение |
| scripts/units | Состояние движения и независимое визуальное представление |
| scripts/navigation | Поиск пути по суше, без обхода юнитов |
| scripts/input | Текущее управление камерой, выделением и приказами |
| scripts/ui | Сетка проходимости |
| scripts/effects | Дорожки и самостоятельный эффект крови |
| scenes/units | Переиспользуемая сцена рыцаря |
| shaders | Шейдеры и общие include-файлы |
| assets | Используемые ресурсы, рыцари, их исходники и лицензии |
| tools | Сборка ресурсов актуального рыцаря |
| tests | Автоматические проверки; не игровые стенды |
| docs/systems | Технические заметки по системам |
| docs/performance, docs/screenshots | Исторические отчёты и галерея, исключены из импорта |

Зависимости: app создаёт мир/камеру/юнитов; input выдаёт приказы через диспетчер;
navigation возвращает путь, unit исполняет его, unit_visual проигрывает анимацию.
Unit3D не содержит боевых таймеров, здоровья, избегания столкновений или тестовых флагов.
ground_blood сохранён как отключённый эффект: будущая боевая система сможет
создать его и вызывать spawn_hit/spawn_death. Сейчас он не создаёт текстур и не работает.

Служебные настройки мира (карта, часы, погода, цветокоррекция) пока находятся
в основной сцене и app/main.gd. Это не финальный игровой HUD.
Сторонние addons и Compositor оставлены на исходных путях, чтобы не ломать плагин.
В .godot хранится локальный кэш движка, он не входит в Git и не является исходниками.

боевые/навигационные прототипы без нового запроса. Контрольная точка до очистки:
