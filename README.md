# RTS Perlin Prototype

Экспериментальный прототип 2D top-down RTS на Godot 4.

## Текущее состояние

- перенесён четырёхоктавный генератор шума Перлина;
- создаются материки, вода и удаляются маленькие острова;
- генерируются лесные массивы, камень, железо и пища;
- карта отрисовывается сверху в обычной квадратной сетке;
- камера двигается зажатым колёсиком и клавишами WASD;
- колесо мыши изменяет масштаб камеры относительно положения курсора;
- новый мир создаётся кнопкой или вводом seed.
- тестовый персонаж перемещается по суше к клетке, выбранной ЛКМ;
- персонаж обходит воду по кратчайшему клеточному пути.
- текущий маршрут персонажа показывается жёлтым пунктиром.
- ПКМ отменяет маршрут; персонаж завершает текущий шаг до ближайшего центра клетки.
- персонаж появляется в глубине крупнейшего связного материка, а не на малом острове.
- панель генератора скрыта из игрового экрана и позже будет вынесена в меню создания мира.
- вода использует оригинальную пиксельную текстуру и медленно анимируется шейдером;
- временная тайловая обводка берега удалена; органичный берег будет отдельной системой.
- суша использует отдельную бесшовную пиксельную текстуру чистой травы без земли.

## План основы

- плоская квадратная логическая сетка;
- отображение сверху (top-down);
- суша и непроходимая вода;
- процедурная генерация карты по шуму;
- деревья, камень, железо и пища;
- перемещение камеры зажатым колёсиком мыши.

Открыть проект можно через файл `project.godot` в менеджере проектов Godot.

ЛКМ пока не используется для приказов юнитам: игровые сущности и базы будут добавлены отдельно.
